# kanta

Python と LLM を中心に、**動くものを作って測る**ところまでを一人でやっています。
ここに置いてあるのは入口だけなので、中身は各リポジトリの README を読んでください。

## いま

- LLM にアプリを操作させるときの **安全な境界** の設計（Tool 経由以外ではデータを変えない）
- 手を動かして検証 → 数字を出す → 直す、のサイクルを回すこと
- 分析を R と Python の両方で実装し、結果が一致することをテストで担保すること

## 使える道具

- **Python** — LLM アプリケーション（FastAPI）、データ処理、統計分析
- **LLM** — Tool Calling の設計、プロバイダの抽象化、応答時間の計測と改善
- **TypeScript / React / Next.js** — `ai-task-manager` のフロントと、このサイト
- **R** — 回帰分析、構造変化の検定
