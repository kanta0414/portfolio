# kanta

Python と LLM を中心に、**動くものを作って測る**ところまでをやっています。
いまは中小製造業の業務自動化を、ヒアリングから実装・導入後の改善まで担当しています。
ここに置いてあるのは入口だけなので、中身は各リポジトリの README を読んでください。

## いま

- クライアントの業務フローをヒアリングして可視化し、AI で自動化して導入まで持っていくこと
- LLM にアプリを操作させるときの **安全な境界** の設計（Tool 経由以外ではデータを変えない）
- 手を動かして検証 → 数字を出す → 直す、のサイクルを回すこと

## 経歴

### 2026.08 –　株式会社AI'm｜AIコンサルティングインターン

中小製造業クライアントの業務フローをヒアリングして可視化し、Claude Code / Codex で自動化を実装。
導入後はクライアント先へ訪問し、運用状況と新たに生じた課題を把握して改善まで担当しています。

### 2026.01 –　株式会社デルタソリューションズ｜法人向け訪問営業インターン

学生3名・社員1名のチームでリーダー。成果が伸びない原因を訪問量ではなくエリアの性質に置き直し、
都市部と地方部で打ち手を分けました。**KPI達成率 190%**（リーダー就任以降は4か月連続達成）。
都市部の訪問数は1日 15 → 23件、地方部の商談化率は 2% → 20%。

### 2020.04 –　滋賀大学 経済学部 経済学科（在学中）

金融市場のリスク構造を数値で検証しています。`works/tepco-kepco-structural-break.md` がその一つです。
